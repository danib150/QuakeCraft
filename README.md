# Plugins di Wild Adventure

Questo e altri plugin sono stati resi pubblici dopo la chiusura di **Wild Adventure**.

Per maggiori informazioni, incluse le versioni Minecraft compatibili e altri progetti rilasciati, consulta la pagina ufficiale:

👉 https://wildadventure.it/plugins

Questo progetto è un aggiornamento di QuakeCraft usando le api spigot 1.21 

---

## 📌 Note importanti

Questo progetto è rivolto principalmente a **programmatori esperti**, perché:

- Il plugin non è production-ready
- La documentazione è minima e limitata ai commenti presenti nel codice.
- Non sono previsti aggiornamenti ufficiali: la manutenzione è a carico dello sviluppatore.

---

## ⚙️ Requisiti di sviluppo

Per compilare correttamente il progetto, è necessario:

- Java 21+ (testato per Minecraft 1.21)
- Paper/Spigot API compatibile con la versione target
- Installare **Lombok** nel proprio IDE:

🔗 https://projectlombok.org/

e aggiungerlo anche come dipendenza nel progetto.

---

## 🛠️ Compatibilità Minecraft

Questo codice è stato originariamente sviluppato per versioni precedenti di Minecraft.

Se lo stai portando su versioni moderne (es. **1.19+ / 1.20+ / 1.21**), potresti dover aggiornare:

- Material (`MOB_SPAWNER` → `SPAWNER`, ecc.)
- Particle (`RED_DUST` → `DUST`, ecc.)
- PotionEffectType (`CONFUSION` → `NAUSEA`, ecc.)
- API deprecated rimosse nelle versioni recenti
